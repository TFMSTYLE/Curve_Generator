# Changelog

## 1.2.2

The source code is now in this repository, with the license it has always been released under.

- Added the GPL 3.0 license text and a copyright notice
- Set the extension id back to curve_generator, the one used on the Blender store
- The package now lists exactly which files it holds
- Restored the store name and tags

## 1.2.1

Released on the Blender store on 2025-10-22.

- Added Tags

## 1.2.0

Released on the Blender store on 2025-10-13.

- Added an option to "Live Refresh" the curve (only use on small setups for stability).
- Added an option to change the Vector handles of all points (from auto to vector).
- Added a new "Peaks" presets to add peaks.
- Added a new Save/Load option to save and load custom curves.

## 1.1.2

Released on the Blender store on 2025-10-11.

- Removed automatic updates from sliders changes to improve performance.
- Curve values are now only applied when clicking "Generate Curve".

## 1.1.0

Released on the Blender store on 2025-10-01.

First Version release.
